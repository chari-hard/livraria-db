Atividade IV - Banco de Dados (BCD)

Aluno: Sistema de Gestão de Livraria

Sobre o Projeto

Esta atividade prática consiste na modelagem, criação, população e consulta de um banco de dados relacional voltado para o comércio de livros, aplicando conceitos de normalização e manipulação avançada de dados via SQL.

Estrutura do Banco de Dados

  • Categorias: Gerenciamento dos gêneros dos livros.
  • Clientes: Cadastro dos compradores.
  • Livros: Catálogo com preços, estoque e vínculos.
  • Pedidos: Controle de compras e datas.
  • Itens_Pedidos: Relociação detalhada dos produtos em cada pedido.

Recursos Técnicos Implementados

  • Criação de Banco de Dados e tabelas relacionais com chaves estrangeiras.
  • Inclusão de massa de dados (mínimo de 5 registros por tabela).
  • 15 Consultas avançadas utilizando INNER JOIN, WHERE, LIKE, GROUP BY, ORDER BY, BETWEEN e SUM.
  • Deploy estruturado na nuvem e versionamento via Git/GitHub.
